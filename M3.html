四張解題便箋

① 因式與倍式

若 A = B × C，且 A、B 為非零多項式，B 就是 A 的因式，A 是 B 的倍式。用除法檢查時，餘式要是 0。

② 先找公因式，再看分組

8x² + 12x = 4x(2x + 3)。數字與字母都要檢查。

x² + 2x + 3x + 6 = x(x + 2) + 3(x + 2) = (x + 2)(x + 3)。分組後找相同的括號。

③ 把乘法公式倒著讀

A² − B² = (A + B)(A − B)
A² + 2AB + B² = (A + B)²
A² − 2AB + B² = (A − B)²

注意：A² + B² 不能套平方差公式；完全平方的中間項要符合 ±2AB。

④ 十字交乘與最後驗算

(ax + b)(cx + d) = acx² + (ad + bc)x + bd。

首項、常數項和交乘和都要吻合。完成後乘開驗算，並確認是否還能分解。

CROSS & DISCOVER

交乘調色盤

目標：2x² + 7x + 3

找出 (ax + b)(cx + d)。改變數值，看交乘結果即時變化。

找因式的三個線索

① ac = 2：二次項係數配對。

② bd = 3：常數項配對。

③ ad + bc = 7：交叉乘後相加。

兩組數字乘積正確，還不代表中間項正確。試著把 b、d 交換，看看發生什麼事。
